# ADR-0004: Паттерны ядра — Hexagonal, Command, FSM, Supervisor, Chain of Responsibility

**Статус**: принят (2026-07-29)

## Контекст

Ядро управляет долгоживущими процессами с интерактивной аутентификацией, множеством
асинхронных отказов (падения, протухшие сертификаты, сон ноутбука) и должно пережить
расширение на новые домены и платформы. Нужен небольшой, но жёсткий набор паттернов,
который не даст логике размазаться.

## Решение

| Паттерн | Роль |
|---|---|
| **Ports & Adapters** | `core` без импортов Electron; внешний мир (Keychain, PTY, exec, настройки, часы, уведомления) — за интерфейсами в `core/ports`, реализации — в `main/adapters`. Граница охраняется eslint-правилом. |
| **Command** | Каждое пользовательское действие — декларативный `Action {id, title, scope, params?, run}` в `ActionRegistry`. Палитра ⌘K, popover трея и хоткеи — просто разные представления одного реестра. |
| **State Machine** | Жизненный цикл сессии (`spawning → awaiting_password/otp → running_probe → healthy ⇄ degraded → exited/failed/restarting`) — явная FSM; UI отображает состояние, переходы валидируются типами. |
| **Supervisor** | `ProxySupervisor` владеет политикой рестартов (exponential backoff, лимит, `restartOnRelogin`), отделённой от механики спавна в `SessionManager`. |
| **Chain of Responsibility + Strategy** | `PromptPipeline`: PasswordHandler → TotpHandler → AskUserHandler; порядок и состав — по конфигу сессии. Новые виды промптов = новый handler, без правки существующих. |
| **Facade** | `TshClient` прячет вызовы CLI, парсинг JSON и версия-специфику Teleport за типизированным API. |
| **Observer** | Типизированные события core → push по IPC → zustand-зеркало. Main — единственный источник правды. |
| **Repository** | Сессии/ring-buffers, настройки, история SQL — за интерфейсами хранилищ. |

Отклонено: DI-контейнер (ручная сборка в composition root прозрачнее), Redux/effector
(логика не живёт в renderer), Event Sourcing (оверкилл), Actor-фреймворки (хватает FSM+Supervisor).

## Последствия

- (+) Core тестируется в чистом Node; фейковый tsh покрывает интеграционные сценарии.
- (+) Расширение (новый прокси-тип, новый промпт, новая платформа, новый источник кредов) —
  добавление кода, не правка.
- (−) Чуть больше файлов/интерфейсов на старте, чем «просто скрипты» — осознанная плата.
